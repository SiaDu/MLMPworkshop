# Assignment 1 — AI Project Survival

Complete this assignment in **your own `MLMPworkshop` GitHub repository**, using `assignment01_AI_Project_Survival/`.

Follow [Workshop 02 — AI Project Survival](../workshop02_AI_Project_Survival/02_AI_Project_Survival.md#7-homework--reproducibility-test) for the two parts: **Build and Document (3 marks)** and **Peer Reproduction (1 mark)**.

## Required submission structure

```text
MLMPworkshop/
└── assignment01_AI_Project_Survival/
    ├── README.md
    ├── Peer_Reproduction.md
    └── evidence/
        ├── input.*
        └── output.*
```

- `README.md`: Repository URL, exact commit, environment, reproducible inference commands, troubleshooting and AI verification.
- `Peer_Reproduction.md`: Reviewer, repository reviewed, PASS/FAIL result, feedback and changes after peer review.
- `evidence/`: One example input and the corresponding generated output.

## Example

See the [Assignment 1 Example](./assign_example/) for the expected file structure and documentation format.

Use the example as a reference. **Do not copy its inference results or troubleshooting records as your own.** The `assign_example/` folder is not an additional folder you need to create in your own submission.

Keep all five assignments in the same GitHub repository. Submit **one GitHub repository link** at the end of the course.

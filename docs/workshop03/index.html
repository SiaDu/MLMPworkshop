SECTION 01 / THE FUNDAMENTALS

What is an AI Agent?

An LLM generates responses. An agent can choose actions, use tools, observe what happens, and decide what to do next.

LLM vs AgentWorkflowTool selectionAgent loop
◇ LLM-ONLY RESPONSE
User prompt→LLM→Text answer

The model responds using the context it has. Without access to tools, it cannot independently search a live database or save a file.

✳ TOOL-USING AGENT
User goal→LLM + tools↻Result

The model can request actions, examine real tool results and adapt its next choice within the application's limits.

01 / UNDERSTAND

What is an LLM API?

An API lets Python send a prompt to a model and receive its answer. Both directions travel through the same API.

LOCAL · YOUR COMPUTER
⌨ Python Script Runs on your PC and calls the Gemini API
REQUEST → ← RESPONSE Over the Internet
GOOGLE CLOUD · REMOTE SERVICE
⇄ Gemini API Receives requests and sends responses
⇄
✳ LLM Model Processes the prompt and generates output
API Key

A private credential linked to your account. Keep it out of GitHub.

Tokens

Units of model input and output, affecting limits and usage.

Rate Limits

Limits on requests or tokens. An HTTP 429 usually means you reached a limit.

Today's model: gemini-3.5-flash-lite via the google-genai Python SDK. Model availability and free-tier limits depend on your Google AI Studio account.

      05 / UNDERSTANDING DATA VALIDATION
      
Understanding Data Validation

      
Structured Outputs help control the response format. They do not guarantee that the generated information is correct, relevant or useful.

    

  


  

    

      1. Schema Validation
      
Are the required fields present, with the correct data types? For example, is search_queries a list of strings?

    

    

      2. Rule Validation
      
Does the output satisfy our additional requirements? For example, are there exactly three search queries?

    

    

      3. Content Validation
      
Are the queries relevant and useful for the research topic? A valid data structure alone cannot tell us.

Direct Python vs LLM Function Calling
The function stays the same. What changes is who chooses to call it, and with which arguments.

      LLM FUNCTION CALLING

Important: Gemini does not directly execute arbitrary Python on your computer. It requests a function call; your application or SDK carries out the permitted function locally.






  
02 / EXTERNAL EVIDENCE
Meet OpenAlex
We are using OpenAlex ↗, an open scholarly-metadata platform. Gemini interprets the task; OpenAlex searches indexed academic records. They are two different APIs.

  

    
✳Gemini APIRequests search_papers(query, limit)

    
⇄

    
⌨Local PythonExecutes tools.py using requests

    
⇄

    
⌕OpenAlex APIReturns paper metadata as JSON

  

  

    
What can it return?
Title, year, authors, DOI, and OpenAlex record URL. Some metadata may be missing.

    
Does it read full papers?
No. Our existing tool retrieves bibliographic metadata, not PDF full text.

    
Need another API Key?
Small anonymous queries are supported. A free OpenAlex API Key increases the daily allowance.

  

  
✓
First test OpenAlex without Gemini. Run python tools.py in your starter folder. It searches for two example records using ordinary Python and the OpenAlex API.

Your first Python Tool
The instructor has already written tools.py. This is a normal Python function, not an LLM by itself. You will run and inspect it, not recreate it.

  
def search_papers(query: str, limit: int = 5) -> list[dict]:

  

    
query: str
Academic search keywords chosen by the program or requested by Gemini.

    
limit: int = 5
Maximum number of papers to request (between 1 and 10).

    
list[dict]
Python list of paper records containing fields such as title, year, and DOI.

  

  
DIRECT CALL · NO LLM INVOLVED

papers = search_papers("facial animation", limit=5)
print(papers)

  
Function Declaration: The Gemini SDK can read a callable's name, docstring and typed parameters, and pass that description to the model. The function's actual Python implementation still runs locally.






  
04 / LET THE SDK HANDLE THE LOOP
Automatic Function Calling
You could write a dispatcher and manually send every function response back to Gemini. For this workshop, we use the Google Gen AI SDK to handle the repeated steps.

  
KEY CODE · SIMPLIFIED FROM THE PROVIDED SCRIPT
from google import genai
from google.genai import types
from tools import search_papers

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.5-flash-lite",
    contents="Use search_papers to find 5 papers about facial animation.",
    config=types.GenerateContentConfig(
        tools=[search_papers]
    ),
)

  

    
Tool Declaration
The SDK shares the function name, description, and parameters with Gemini.

    
Tool Execution
The SDK receives the requested arguments and runs the allowed Python function.

    
Tool Response
The SDK sends returned data back to Gemini so it can prepare an answer.

  

  
One user message, potentially multiple Gemini API calls. The SDK can handle the tool-request/result exchange internally. In our full 03_function_calling.py example, a small logging wrapper makes that hidden execution visible.

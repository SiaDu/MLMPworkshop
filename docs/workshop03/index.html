SECTION 01

What is an AI Agent?

An LLM generates responses. An agent can choose actions, use tools, observe what happens, and decide what to do next.

◇ LLM-ONLY RESPONSE
User prompt→LLM→Text answer

The model responds using the context it has. Without access to tools, it cannot independently search a live database or save a file.

✳ TOOL-USING AGENT
User goal→LLM + tools↻Result

The agent can choose a tool, use its results, and decide what to do next.

What is an LLM API?

An API lets Python send a prompt to Gemini and receive an answer.

LOCAL · YOUR COMPUTER
⌨ Python Script Runs on your PC and calls the Gemini API
REQUEST → ← RESPONSE Over the Internet
GOOGLE CLOUD · REMOTE SERVICE
⇄ Gemini API Receives requests and sends responses
⇄
✳ LLM Model Processes the prompt and generates output
API Key

A private credential linked to your account. Keep it out of GitHub.

Tokens

Units of model input and output, affecting limits and usage.

Rate Limits

Limits on requests or tokens. An HTTP 429 usually means you reached a limit.

Today's model: gemini-3.5-flash-lite via the google-genai Python SDK. Model availability and free-tier limits depend on your Google AI Studio account.

      F / VALIDATION
      
What Does Validation Check?

      
Structured Outputs control the format, not the accuracy of the information.

    

  


  

    

      1. Schema Validation
      
Are the required fields present, with the correct data types? For example, is search_queries a list of strings?

    

    

      2. Rule Validation
      
Does the output satisfy our additional requirements? For example, are there exactly three search queries?

    

    

      3. Content Validation
      
Are the queries relevant and useful for the research topic? A valid data structure alone cannot tell us.

A / OPENALEX
Meet OpenAlex
OpenAlex ↗ is a database of academic paper information. Gemini helps decide what to search for, while OpenAlex finds the papers. We connect to both through APIs.

  

    
✳Gemini APIChooses search_papers(query, limit)

    
⇄

    
⌨Local PythonRuns our Python search function

    
⇄

    
⌕OpenAlex APIReturns paper metadata as JSON

  

  

    
What can it return?
Title, year, authors, DOI, and OpenAlex record URL. Some metadata may be missing.

    
Does it read full papers?
No. Our existing tool retrieves bibliographic metadata, not PDF full text.

    
OpenAlex Free Tier
Without an API Key: Approximately 100 paper searches per day.
With a Free API Key: Approximately 1,000 paper searches per day.
Results per Search: OpenAlex supports up to 100 papers per request, but our workshop tool limits this to 10.

C / AUTOMATIC CALLING
Automatic Function Calling
Instead of choosing the search keywords ourselves, we can let Gemini choose them. The Google Gen AI SDK handles the Function Calling steps for us.

  
EXAMPLE CODE
from google import genai
from google.genai import types
from tools import search_papers

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.5-flash-lite",
    contents="Use search_papers to find 5 papers about facial animation.",
    config=types.GenerateContentConfig(
        tools=[search_papers]
    ),
)

  
We provide search_papers() to Gemini as a tool. Gemini chooses the search keywords and paper count, and the SDK runs the Python function.

01 / UNDERSTAND
How does RAG work?
The LLM does not need to read every page for every question. Python retrieves relevant chunks first.

Chunking
Split long paper text into smaller chunks, keeping page numbers.

    
Retrieval
Find chunks that may answer a question. Our script uses BM25 keyword matching.

    
Generation

BM25 vs. EmbeddingsBM25 matches words and keywords. Embedding-based retrieval can match semantic similarity. Today we use BM25 — no vector database or Embedding API required.

04 / VERIFY
Retrieved ≠ Correct.
Structured JSON and valid chunk IDs help you trace answers, but they do not prove the answer is accurate.

  

  

    

      evidence.json · example structure
      
{
  "answer": "Accuracy, IoU, ...",
  "evidence_ids": ["C0049"],
  "evidence": [
    { "id": "C0049", "page": 8, "text": "..." }
  ]
}

      Chunk IDs vary by PDF and by extraction run.
    

    

      YOUR TWO-FIELD CHECK
      
1
Choose two extracted fields in literature_review.csv.

      
2
Find the answers, chunk IDs and page numbers in evidence.json.

      
3
Read the matching text in your original PDF. Does the evidence support the answer?

      
“Not found in retrieved evidence” does not mean the paper never mentions it. The retriever may simply have missed it.

01 / UNDERSTAND

          
One HTTP request. Three possible responses.

          
In Section 3 you called OpenAlex through requests.get(). Web scraping often starts with the same Python request — but the server may return JSON, HTML, or file bytes.

        

        

          

            01 / API · JSON
            
Structured data

            
An API gives Python named fields, such as a paper's PDF URL.

            response.json()
          

          

            02 / WEBPAGE · HTML
            
Page structure

            
BeautifulSoup reads HTML elements and extracts attributes.

            BeautifulSoup(response.text)
          

          

            03 / DOWNLOAD · PDF
            
File content

            
Python saves the returned bytes and validates the PDF.

            response.content
          

        

        
Key idea: If an API already provides a working PDF URL, there is no reason to scrape HTML. Scraping is useful when the link is hidden inside a webpage. A URL alone does not guarantee a successful download.

04 / THINK LIKE A DEVELOPER

          
What can a download really prove?

          
Three common mistakes when automating research downloads.

        

        

          

            ACCESS
            
HTTP 403 ≠ Paywall

            
The server rejected the request. We cannot conclude why. Respect robots.txt and use permitted alternative sources or manual links.

          

          

            FILE VALIDATION
            
HTTP 200 ≠ Valid PDF

            
A successful HTTP response might contain an HTML login page. Check the PDF signature and confirm the file opens correctly.

          

          

            ACADEMIC QUALITY
            
Downloaded ≠ Reliable

            
A real paper may be irrelevant or retracted. OpenAlex's is_retracted flag is useful, but never replaces academic verification.

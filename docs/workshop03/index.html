SECTION 01 / THE FUNDAMENTALS

What is an AI Agent?

An LLM generates responses. An agent can choose actions, use tools, observe what happens, and decide what to do next.

LLM vs AgentWorkflowTool selectionAgent loop
◇ LLM-ONLY RESPONSE
User prompt→LLM→Text answer

The model responds using the context it has. Without access to tools, it cannot independently search a live database or save a file.

✳ TOOL-USING AGENT
User goal→LLM + tools↻Result

The model can request actions, examine real tool results and adapt its next choice within the application's limits.

01 / UNDERSTAND

What is an LLM API?

An API lets Python send a prompt to a model and receive its answer. Both directions travel through the same API.

⌨Python ProgramSends a prompt; receives text or JSON
⇄
⇄Gemini APITransfers requests and responses
⇄
✳LLM ModelProcesses the prompt and generates output
REQUEST →Python → API → Model
← RESPONSEModel → API → Python (text / JSON)
API Key

A private credential linked to your account. Keep it out of GitHub.

Tokens

Units of model input and output, affecting limits and usage.

Rate Limits

Limits on requests or tokens. An HTTP 429 usually means you reached a limit.

Today's model: gemini-3.5-flash-lite via the google-genai Python SDK. Model availability and free-tier limits depend on your Google AI Studio account.

02 / FIRST API CALL

Ask Gemini from Python

A prompt goes through the Gemini API; Python receives the response as text. The complete working file is included in your download.

THE KEY IDEA · PYTHON

client = genai.Client()

response = client.models.generate_content(
    model="gemini-3.5-flash-lite",
    contents="Suggest 3 research queries about AI facial animation."

print(response.text)

04 / HANDS-ON
Structured Outputs with Pydantic
Tell Gemini exactly what shape of JSON you need. Python validates the response and saves it for the paper-search tool.

  

    
topic: str
A string: your survey topic.

    
search_queries: list[str]
A list of research-query strings.

    
start_year: int
An integer: the start of the publication period.

  

  

    PYDANTIC · DEFINE THE OUTPUT STRUCTURE
    
class SearchPlan(BaseModel):
    topic: str
    search_queries: list[str]
    start_year: int

  

  
Structured output: pass response_schema=SearchPlan with JSON response mode. Use SearchPlan.model_validate_json(...) to check the returned data.

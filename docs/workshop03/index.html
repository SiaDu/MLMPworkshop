SECTION 01

What is an AI Agent?

An LLM generates responses. An agent can choose actions, use tools, observe what happens, and decide what to do next.

◇ LLM-ONLY RESPONSE
User prompt→LLM→Text answer

The model responds using the context it has. Without access to tools, it cannot independently search a live database or save a file.

✳ TOOL-USING AGENT
User goal→LLM + tools↻Result

The agent can choose a tool, use its results, and decide what to do next.

What is an LLM API?

An API lets Python send a prompt to Gemini and receive an answer.

LOCAL · YOUR COMPUTER
⌨ Python Script Runs on your PC and calls the Gemini API
REQUEST → ← RESPONSE Over the Internet
GOOGLE CLOUD · REMOTE SERVICE
⇄ Gemini API Receives requests and sends responses
⇄
✳ LLM Model Processes the prompt and generates output
API Key

A private credential linked to your account. Keep it out of GitHub.

Tokens

Units of model input and output, affecting limits and usage.

Rate Limits

Limits on requests or tokens. An HTTP 429 usually means you reached a limit.

      F / VALIDATION
      
What Does Validation Check?

      
Structured Outputs control the format, not the accuracy of the information.

    

  


  

    

      1. Schema Validation
      
Are the required fields present, with the correct data types? For example, is search_queries a list of strings?

    

    

      2. Rule Validation
      
Does the output satisfy our additional requirements? For example, are there exactly three search queries?

    

    

      3. Content Validation
      
Are the queries relevant and useful for the research topic? A valid data structure alone cannot tell us.

C / AUTOMATIC CALLING
Automatic Function Calling
Instead of choosing the search keywords ourselves, we can let Gemini choose them. The Google Gen AI SDK handles the Function Calling steps for us.

  
EXAMPLE CODE
from google import genai
from google.genai import types
from tools import search_papers

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.5-flash-lite",
    contents="Use search_papers to find 5 papers about facial animation.",
    config=types.GenerateContentConfig(
        tools=[search_papers]
    ),
)

  
We provide search_papers() to Gemini as a tool. Gemini chooses the search keywords and paper count, and the SDK runs the Python function.

Split long paper text into smaller chunks, keeping page numbers.

Gemini's conversation alone is not enough to track files between program runs. Python stores research state in state/library.json, reads files in papers/, and records finished analysis in method_comparison.csv. A PDF's SHA-256 fingerprint helps identify unchanged files.

D / FAILURES & LIMITATIONS

          
Making Decisions Doesn't Guarantee Success.

          
Our Agent can search for papers, download PDFs and extract information into a structured table. But a successful workflow does not necessarily produce a good literature review. The researcher must still judge relevance, evaluate quality, check extracted information and critically compare the findings.

        


        

          

            
01PAPER SELECTION

            
Research Relevance

            
Is this paper actually relevant?

            
A broad topic may return papers that share the same keywords but investigate different research questions.

            
RESEARCHER'S ROLE
Refine the research question and define inclusion and exclusion criteria.

          

          

            
02SOURCE EVALUATION

            
Publication Quality

            
Is this a credible research source?

            
Search results may include less selective venues, unreviewed preprints or studies with weak methodology. Venue ranking alone does not establish quality.

            
RESEARCHER'S ROLE
Check peer-review status, venue reputation and the quality of methods and evidence.

          

          

            
03COMPARISON DESIGN

            
Paper Type Mismatch

            
Does every paper fit the same table?

            
Survey papers and non-ML methods may not propose a new neural network, training dataset or directly comparable evaluation metrics.

            
RESEARCHER'S ROLE
Identify paper types and adapt comparison categories rather than forcing every paper into one schema.

          

          

            
04EVIDENCE CHECKING

            
LLM Extraction Errors

            
Is the extracted information correct?

            
The LLM may confuse a proposed method with a baseline, misidentify a dataset or misinterpret evaluation results.

            
RESEARCHER'S ROLE
Verify important fields against the original PDF and its supporting evidence.

          

        


        

          FROM INFORMATION EXTRACTION TO CRITICAL SYNTHESIS
          
A Completed Table Is Not a Literature Review.

          
A literature review must compare approaches, explain strengths and weaknesses, identify trends and contradictions, and discuss remaining research gaps.

          
The Agent helps collect and organise evidence. The researcher is responsible for interpreting and synthesising it.

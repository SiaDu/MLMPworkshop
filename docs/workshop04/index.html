SECTION 00 · MOTION DATA

Why divide frame numbers by 30?

At 30 fps, 30 frames last one second. So x = frame / 30 gives time in seconds, from 0 to 1. This is a change of units, not a requirement of linear regression. We could use frame numbers, but the numerical scale would be larger and the learning rate might need to change.

x = frame / fps   ·   15 / 30 = 0.5 s
SECTION 01 · PYTHON FOUNDATIONS

Write and read basic Python.

Python uses variables, lists, conditions, loops, and functions. These are the building blocks of the model you will write in the Notebook.

Variables and names

A variable stores a value. Use = to assign a value. Python names are case-sensitive: frame and Frame are different names.

Valid names
frame = 3
frame_rate = 30
position_x = 1.52
is_moving = True
_position = 0
Invalid names
2frames = 10   # cannot start with a digit
frame rate = 30 # no spaces
frame-rate = 30 # '-' means subtraction
if = 3         # 'if' is a keyword

Names can use letters, digits and underscores, but cannot start with a digit. Choose clear names, usually snake_case. Avoid replacing built-in names such as list, sum or print.

List, index, len() and print()

A list contains several values. An index starts at 0. len() counts items. print() displays a value.

positions = [1.52, 1.97, 2.55]
print(positions[0])  # 1.52: first item
print(positions[-1]) # 2.55: last item
print(len(positions)) # 3
print(positions[:2]) # [1.52, 1.97]

for, if, elif, else

Use a loop to visit values. Conditions choose which block runs. Indentation shows what belongs to each block.

Loop over values
for position in positions:
    print(position)

for i in range(len(positions)):
    print(i, positions[i])
Check a condition
speed = 2
if speed > 3:
    print("Fast")
elif speed == 3:
    print("Medium")
else:
    print("Slow")

== checks equality, while = assigns a value. range(len(...)) gives indices when the position of each item matters.

def, return, and print()

def defines a function. Parameters are the inputs. return sends a value back to the code that called the function. print() only displays it.

def double(value):
    return value * 2

result = double(3) # result is 6
print(result)      # shows 6

def show_double(value):
    print(value * 2)

other = show_double(3) # prints 6
print(other)            # prints None

The Notebook asks you to write functions that return answers so other functions can reuse them.

Element-wise vs matrix multiplication

[1, 2] * [0.2, 0.8] = [0.2, 1.6]
[1, 2] @ [0.2, 0.8] = 1.8

With *, multiply matching elements. With @, multiply and add. Each input row produces one prediction.

Transpose changes the shape

X: (3, 2) → Xᵀ: (2, 3)

Transpose swaps rows and columns. This will matter when calculating the gradient for each feature.

X.T is the NumPy syntax for a 2D transpose. For a 1D array, x.T is still 1D; x.reshape(-1, 1) creates a column.

How do we measure the error?

The residual for each sample is the predicted position minus the measured position. The loss combines residuals into one number.

errori = ŷi − yi
loss = MSE = (1/N) Σi=1…N (errori)²
1. Subtract: Find the residual for each sample.
2. Square: Positive and negative residuals cannot cancel.
3. Take the mean: Sum squared residuals and divide by N samples.
Your main course may use J = MSE / 2. We use loss = MSE. Both have the same minimum, but the derivative of MSE has an extra factor 2.
SECTION 04 · GRADIENT DESCENT

How does the model learn?

Instead of moving the line by hand, gradient descent updates its parameters. A derivative tells us how a value changes. A partial derivative tells us how loss changes when we change one parameter at a time.

Follow the chain rule

For one sample, we calculate prediction → residual → squared residual. To find the effect of a weight change, follow the same chain backwards.

1 · Prediction: ŷ = wx + b
2 · Residual: error = ŷ − y
3 · Squared residual: squared error = error²
4 · Chain rule for w: ∂(error²)/∂w = (∂(error²)/∂error) × (∂error/∂ŷ) × (∂ŷ/∂w) = 2 × error × 1 × x
5 · Chain rule for b: ∂(error²)/∂b = 2 × error × 1 × 1

Average these contributions across all N samples to obtain the MSE gradients.

dw = (2/N) Σ(errori × xi)
db = (2/N) Σ(errori)
dw — weight gradientHow loss changes as weight w changes.
db — bias gradientHow loss changes as bias b changes.
α — learning rateThe size of each update step.
EpochOne complete pass over the training samples.
wnew = w − α × dw
bnew = b − α × db

SECTION 05 · MULTIPLE FEATURES

A curved path from two features.

For accelerating motion, the horizontal position changes faster over time. We can add x² as a second input feature. The output is still just one horizontal position per sample.

One feature: ŷ = wx + b
Two features: ŷ = w₁x + w₂x² + b

Compare a straight line with a curve

The curves shown here are illustrative models. You will train your own parameters in the Notebook.

Why is this still linear regression? The output is curved in x, but the model is a sum of weights times fixed features x and x². This is called polynomial regression. It is not logistic regression, which is used for classification.

Why transpose the input matrix?

Each row is a sample. Each column is a feature. During training, every feature needs its own gradient, so the calculation must sum the residual-weighted values down each feature column.

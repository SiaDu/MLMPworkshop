Why use time in seconds?

SECTION 01 · PYTHON FOUNDATIONS

Python Foundations

Python uses variables, lists, conditions, loops, and functions. These are the building blocks of the model you will write in the Notebook.

Variables and names

A variable stores a value. Use = to assign a value. Python names are case-sensitive: frame and Frame are different names.

Valid names
frame = 3
frame_rate = 30
position_x = 1.52
is_moving = True
_position = 0
Invalid names
2frames = 10   # cannot start with a digit
frame rate = 30 # no spaces
frame-rate = 30 # '-' means subtraction
if = 3         # 'if' is a keyword

Names can use letters, digits and underscores, but cannot start with a digit. Choose clear names, usually snake_case. Avoid replacing built-in names such as list, sum or print.

List, index, len() and print()

A list contains several values. An index starts at 0. len() counts items. print() displays a value.

positions = [1.52, 1.97, 2.55]
print(positions[0])  # 1.52: first item
print(positions[-1]) # 2.55: last item
print(len(positions)) # 3
print(positions[:2]) # [1.52, 1.97]

for, if, elif, else

Use a loop to visit values. Conditions choose which block runs. Indentation shows what belongs to each block.

Loop over values
for position in positions:
    print(position)

for i in range(len(positions)):
    print(i, positions[i])
Check a condition
speed = 2
if speed > 3:
    print("Fast")
elif speed == 3:
    print("Medium")
else:
    print("Slow")

== checks equality, while = assigns a value. range(len(...)) gives indices when the position of each item matters.

def, return, and print()

def defines a function. Parameters are the inputs. return sends a value back to the code that called the function. print() only displays it.

def double(value):
    return value * 2

result = double(3) # result is 6
print(result)      # shows 6

def show_double(value):
    print(value * 2)

other = show_double(3) # prints 6
print(other)            # prints None

The Notebook asks you to write functions that return answers so other functions can reuse them.

SECTION 02 · NUMPY & SHAPES

NumPy & Shapes

A NumPy array stores numbers and supports mathematical operations. In a model's input matrix, rows are samples and columns are features.

Step 1 · Matrix multiplication

For @, multiply one row by the weight vector, then add the products.

[1, 2] @ [10, 20] = 1 × 10 + 2 × 20 = 50
[3, 4] @ [10, 20] = 3 × 10 + 4 × 20 = 110
[[1, 2], [3, 4]] @ [10, 20] = [50, 110]

Shape (2, 2) @ (2,) → (2,). The inner dimensions must match.

Step 2 · Broadcasting

After the matrix multiplication, one scalar bias is added to each prediction.

[50, 110] + 5 = [55, 115]

NumPy broadcasting lets the same value be added to every result.

SECTION 03 · PREDICTION & LOSS

Prediction & Loss

A linear model predicts horizontal position from time in seconds. You already know how to change a line’s slope and shift it up or down. In machine learning these same controls are called weight (w) and bias (b).

\[\hat y=wx+b\]
Same line, new names: w (weight) controls the slope — how steeply the line rises or falls. b (bias) shifts the entire line up or down without changing the slope. These are the controls you already used.
x — inputTime in seconds (0 to 1 in this dataset).
ŷ — predictionThe position calculated by the model.
w — weightThe slope: how much the prediction changes when x rises by 1.
b — biasThe predicted position at x = 0.

Try a weight and bias

MSE (loss)–
Modelŷ = 3x + 0
Measured positionPredictionResidual

How do we measure the error?

The residual for each sample is the predicted position minus the measured position. The loss combines residuals into one number.

\[\mathrm{error}_i=\hat y_i-y_i\]\[\mathrm{Loss}=\mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2\]
1. Subtract: Find the residual for each sample.
2. Square: Positive and negative residuals cannot cancel.
3. Take the mean: Sum squared residuals and divide by N samples.

SECTION 04 · GRADIENT DESCENT

Gradient Descent

In Section 03, you changed the weight (w) and bias (b) by hand to reduce the loss. Gradient Descent lets the model update them automatically: calculate how each parameter affects the loss, then take a small step in the direction that reduces it.

Step 1 · What happens when we change a parameter?

Start with one sample: x = 2 (input), y = 5 (correct value), w = 1, b = 0.

Prediction: ŷ = wx + b = 1 × 2 + 0 = 2
Error: ŷ − y = 2 − 5 = −3
Squared error (L): error² = (−3)² = 9

Try changing one parameter at a time. Keep everything else fixed.

ExperimentPredictionLoss
Original: w = 1, b = 029
Increase w to 1.1 (keep b = 0)2.27.84 ↓
Increase b to 0.1 (keep w = 1)2.18.41 ↓

Both changes reduce the loss, but by different amounts. How can we calculate which way to change each parameter without trying every possible value?

Step 2 · Understanding derivatives

Differentiation is the process of calculating a derivative. A derivative describes how quickly an output changes when an input changes slightly.

If a function depends on multiple variables, we use partial differentiation: change only one variable and keep the others constant. Its result is a partial derivative.

Ordinary derivative: dOne input: f(t) = t²
df/dt = 2t
How f changes as t changes.
Partial derivative: ∂Two parameters: ŷ = wx + b
∂ŷ/∂w = x
Change w; keep x and b fixed.

We want the two gradients ∂L/∂w and ∂L/∂b: how the loss changes when we change w or b. The sign of a gradient tells us which direction reduces the loss locally.

Positive gradient (+)

Increasing the parameter increases the loss. Move left to reduce it.

Negative gradient (−)

Increasing the parameter decreases the loss. Move right to reduce it.

These show local directions at the marked points. The gradient may change as the parameter moves. A zero gradient means the loss is locally flat with respect to that parameter.

Step 3 · Follow the chain of changes

Start with the numbers, not calculus. Let x = 2, y = 5, w = 1 and b = 0. Increase only w by 0.1. Keep the input, correct answer and bias unchanged. Watch how the change moves through the model.

Changing w affects the loss indirectly, through prediction and error.

Weightw: 1 → 1.1
→
Predictionŷ: 2 → 2.2
→
Error−3 → −2.8

Loss9 → 7.84
1 · Prediction: w increases by 0.1. Because x = 2, the prediction increases by 0.1 × 2 = 0.2.
2 · Error: y stays at 5. Error also increases by 0.2, from −3 to −2.8. That brings the error closer to zero.
3 · Loss: square the error. The loss decreases from 9 to 7.84, a decrease of 1.16.

Now we want a rule that works for very small changes. A derivative is the local rate of change. At our original values (x = 2, error = −3), the three local rates are:

RelationshipRateMeaning
w → Prediction2Changing w slightly changes prediction twice as much.
Prediction → Error1Prediction and signed error change by the same amount.
Error → Loss−6Near error = −3, increasing error slightly decreases loss.

Each row describes one link in the chain. Multiply the three rates to get the overall effect of w on the loss. This is the Chain Rule:

2 × 1 × (−6) = −12

This multiplication is the Chain Rule. It combines the rates of change along the chain. The negative result means a small increase in w will initially lower the loss.

Small changes matter: The derivative is a local rate, not the exact loss change for a large step. In Step 1 we increased w by 0.1, so the exact change in loss is −1.16 rather than −12 × 0.1 = −1.2.

Step 4 · Calculate the gradients (Optional)

You do not need the full differentiation to use Gradient Descent. Here are the final equations for one sample:

\[dw=2\,\mathrm{error}\,x\]
\[db=2\,\mathrm{error}\]

These tell us how changing the weight (slope) or bias (vertical shift) affects the squared error. Expand the details only if you want to see where they come from.

Show the differentiation rules and Chain Rule derivation

How did we get the rates 2, 1 and −6? We use four basic differentiation rules:

RuleExampleDerivative
1. Constant → 0f(t) = 5df/dt = 0
2. Variable → 1f(t) = tdf/dt = 1
3. Constant × variable → constantf(t) = 3tdf/dt = 3
4. Squared variable → 2 × variablef(t) = t²df/dt = 2t

These rules also work for partial derivatives; just remember which variables you are holding constant.

1. Prediction changes with w

ŷ = wx + b. Change w; keep x and b constant. The b term contributes 0 because b does not change.

∂ŷ/∂w = x + 0 = x
2. Prediction changes with b

Keep w and x constant. The wx term contributes 0; b changes at a rate of 1.

∂ŷ/∂b = 0 + 1 = 1
3. Error changes with prediction

error = ŷ − y. The correct value y stays constant, so its derivative is 0.

∂error/∂ŷ = 1 − 0 = 1
4. Squared error changes with error

L = error². Use Rule 4 (the power rule). Here L is a function of one variable, error.

dL/d(error) = 2 × error

Now apply the Chain Rule to get the gradient for w:

∂L/∂w = (2 × error) × 1 × x
dw = 2 × error × x

For b, the last rate is 1 instead of x:

∂L/∂b = (2 × error) × 1 × 1
db = 2 × error

Try the numbers

With x = 2 and error = −3:

dw = 2 × (−3) × 2 = −12
db = 2 × (−3) = −6

These formulas are for a single sample's squared error. Next, we average across all samples.

Step 5 · From one sample to many samples

Real datasets contain many training samples. Our loss is Mean Squared Error (MSE): average the squared errors across all N samples.

\[\mathrm{MSE}=\frac{1}{N}\sum_{i=1}^{N}(\mathrm{error}_i)^2\]

Calculate each sample's contribution to dw and db, then take the average:

\[dw=\frac{2}{N}\sum_{i=1}^{N}\mathrm{error}_i x_i\]
\[db=\frac{2}{N}\sum_{i=1}^{N}\mathrm{error}_i\]

N is the number of samples; Σ means add the values across all samples. The 2 comes from differentiating the square, and 1/N comes from averaging.

Why do some courses use 1/N instead of 2/N?

Some courses define the loss as J = MSE/2. This removes the factor of 2 from the gradient formulas. Both losses have the same optimal parameters, but MSE/2 produces gradients that are half as large at the same parameter values (for example, −6 instead of −12). This workshop and the Notebook use MSE, so our gradient formulas keep the 2.

Step 6 · Update the parameters

Gradient Descent moves against the gradient. The learning rate α (alpha) controls the step size.

wnew = w − α × dw
bnew = b − α × db

Return to our one-sample example: w = 1, b = 0, dw = −12, db = −6. Choose α = 0.01.

wnew = 1 − 0.01 × (−12)
= 1.12
bnew = 0 − 0.01 × (−6)
= 0.06

The new prediction is 1.12 × 2 + 0.06 = 2.30, and the squared error decreases from 9 to 7.29. Gradient Descent repeats these updates to find better parameters.

dw — weight gradientHow loss changes as weight w changes.
db — bias gradientHow loss changes as bias b changes.
α — learning rateControls the size of each update.
